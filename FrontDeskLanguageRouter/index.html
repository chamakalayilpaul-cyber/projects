Goal

Detects the caller's spoken or written language before anything else, then hands the conversation to a fully native-language procedure set — English or Spanish — so greetings, intent detection, scheduling, and escalation all run in the caller's own language. Falls back to a bilingual human transfer when the language can't be confidently detected.
